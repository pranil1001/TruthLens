# TruthLens

> AI-Powered Fake News Detection Chrome Extension

TruthLens is a production-ready Chrome Extension that analyzes online news articles using Artificial Intelligence and Rule-Based Analysis to provide an explainable credibility score.

Instead of simply labeling news as "Fake" or "Real", TruthLens explains *why* an article receives its credibility score through Explainable AI (XAI), source reputation analysis, evidence evaluation, and language analysis.

---

## Features

### AI Analysis

- Fake News Detection
- AI Summary
- Bias Detection
- Emotion Analysis
- Explainable AI
- Confidence Score

---

### Rule-Based Analysis

- HTTPS Verification
- Domain Reputation
- Citation Analysis
- Headline Quality
- Metadata Validation
- Source Reliability

---

### Hybrid Scoring

TruthLens combines

- **40% Rule-Based Analysis**
- **60% AI Analysis**

to generate a final credibility score.

## Installation

Clone the repository

```bash
git clone https://github.com/pranil1001/TruthLens.git
```

Navigate into the project

```bash
cd TruthLens
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build the extension

```bash
npm run build
```
